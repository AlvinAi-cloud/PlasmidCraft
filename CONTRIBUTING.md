# Contributing

Read README.md for prerequisites and test commands. Keep biology calculations in pure modules with coordinate/strand conventions stated, preserve native document compatibility, and add meaningful regression coverage for correctness changes. Run unit, UI and native Rust checks before submitting a pull request. New data needs source attribution, retrieval/version metadata and redistribution terms. Do not copy commercial annotation databases or user sequences into the repository.

UI changes should remain usable at the minimum desktop window size and support keyboard operation. Native/network actions must preserve explicit review and restricted file access. Do not commit secrets, OAuth tokens, build caches, SDKs, target folders or installer binaries. Release assets belong in GitHub Releases. Describe the issue, resulting behavior and validation in each contribution.
