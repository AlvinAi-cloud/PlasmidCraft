# PlasmidCraft 0.37

- Simplified AI workspace with active-plasmid context and optional attached templates.
- AI gene replacement, custom local computation, supported API cloud fallback, result summaries and duplicate-operation protection.
- Bulk removal of selected features with Undo.
- Improved primer mismatch, insertion and deletion display.

- Linux distribution now uses an amd64 Debian package instead of AppImage.

Prepared by Huiwang Ai at the University of Virginia with ChatGPT Codex. Contact: huiwang.ai@virginia.edu.

Feature lists can be imported from an existing SnapGene installation; instructions are in Help → Feature libraries and exchange. Vendor databases are not bundled.

Mac packages are ad-hoc signed without notarization; Windows is unsigned. Live AI-provider execution and target-device acceptance remain separate from automated tests. Keep .pcraft master documents; there is no autosave or crash recovery.
