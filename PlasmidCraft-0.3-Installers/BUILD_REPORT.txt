LIMITS / TARGET-DEVICE ACCEPTANCE
Apple Silicon and Windows are cross-built on Intel. Installation/execution on
those targets remains pending. Renderer checks simulate native dialogs and provider
services; live paid AI requests, ChatGPT eligibility, real NCBI submissions and
fresh-download trust prompts were not tested in this review. Hosted GitHub CI
has not run. Native acceptance checklist: docs/VALIDATION.md.
Mac API keys support Keychain persistence; Windows keys remain session-only.
No autosave/crash recovery. Sequence calculations do not establish experimental
yield. No GitHub upload or publication was performed.
