# Privacy in PlasmidCraft 0.34

Documents, sequence calculations and design previews run locally. The app does not automatically upload files or collect analytics. Native file access is granted by user-selected dialogs; native writes are limited to those paths. Feature libraries and settings may persist in the local application profile. DNA/protein documents need explicit saves; local profile storage is not a document backup.

AI is optional. Review the message and sharing controls before Send; External AI also provides a prepared prompt preview. API connections are remembered by default in the application's local configuration, at `api/connection.json` under the app configuration folder. The key, provider, endpoint and selected model are stored as local JSON on this computer, outside plasmid documents and exports. On Unix systems the file and folder are restricted to the current user. Saved connections restore into native memory at startup without contacting the provider or requesting Keychain authorization. **Forget saved connection** clears the current saved credential and disconnects; an explicit session-only option is also available. Older Mac Keychain connections are imported only when they can be read without an authentication dialog. Forgetting a connection prevents an old Keychain entry from being reimported; the old entry itself remains available to older app versions. Nonsecret display preferences are stored in the local app profile. Connected conversations and operation summaries are saved locally per document in a bounded profile store. Recent-history sharing is enabled by default for connected conversations and can be disabled. Messages and selected history are sent as written and can contain pasted DNA; Internal AI shares active-document DNA by default when you send a request; its visible sharing checkbox can disable this and remembers your choice. External AI document-DNA sharing defaults off. Tool-generated oligo sharing is controlled separately. The external workflow retains explicit prompt copying and proposal review. ChatGPT account tokens are saved in separate local files under the app configuration’s `chatgpt/sessions/` folder on every desktop platform. Nonsecret account metadata and last-used selection are stored separately in `chatgpt/accounts.json`. Unix permissions restrict these files/folders to the current user. The last-used eligible account reconnects automatically and renews access when needed. Sign-out clears that session and prevents automatic reconnection or switching to a different saved account. Readable legacy Mac Keychain sessions can be imported without an authentication dialog. Provider sign-in, model discovery and AI requests contact the selected service. Account/provider terms, eligibility, retention and API charges apply. Live ChatGPT eligibility and non-Mac login flows remain acceptance checks for 0.34.

NCBI BLAST uploads only a reviewed query when Submit is chosen. NCBI receives that sequence and ordinary network request metadata. Results open on NCBI in the system browser. The app does not repeatedly poll NCBI. An Internet connection is required for submission and results. Website links also contact their destination in the browser.

AI/provider responses cannot directly execute commands or read arbitrary files. Connected AI can invoke a bounded set of validated local design tools on a copy after you click Send. Successful designs open as new unsaved documents; original documents are preserved. External pasted proposals require explicit review and application. Do not send confidential context to an external service without deciding that its terms fit your work.

The release source folder and test installers contain the supplied pET-21b(+) example, public reference records, synthetic workflow/test examples and test-only cryptographic fixtures. They contain no private working documents or actual account credentials. Developer UI checks can download public checksum-pinned test samples, excluded from the app and release source folder.
