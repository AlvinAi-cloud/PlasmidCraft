# Privacy in PlasmidCraft 0.32

Documents, sequence calculations and design previews run locally. The app does not automatically upload files or collect analytics. Native file access is granted by user-selected dialogs; native writes are limited to those paths. Feature libraries and settings may persist in the local application profile. DNA/protein documents need explicit saves; local profile storage is not a document backup.

AI is optional. Review the message and sharing controls before Send; External AI also provides a prepared prompt preview. The Mac app saves API keys in macOS Keychain when **Remember on this device** is selected (enabled by default). Saved keys are restored into native memory at startup without contacting the provider. **Forget saved connection** deletes the saved item and disconnects; an explicit session-only option is also available. Other platforms currently require that session-only option for API connections; nonsecret provider, endpoint and model preferences are stored in the local app profile. Connected conversations and operation summaries are saved locally per document in a bounded profile store. Recent-history sharing is enabled by default for connected conversations and can be disabled. Messages and selected history are sent as written and can contain pasted DNA; Internal AI shares active-document DNA by default when you send a request; its visible sharing checkbox can disable this and remembers your choice. External AI document-DNA sharing defaults off. Tool-generated oligo sharing is controlled separately. The external workflow retains explicit prompt copying and proposal review. ChatGPT account tokens use macOS Keychain where available; account metadata is stored separately in the local app configuration. On platforms without a configured secure credential store, account tokens remain in session memory. Provider sign-in, model discovery and AI requests contact the selected service. Account/provider terms, eligibility, retention and API charges apply. Live ChatGPT eligibility and non-Mac login flows remain acceptance checks for 0.32.

NCBI BLAST uploads only a reviewed query when Submit is chosen. NCBI receives that sequence and ordinary network request metadata. Results open on NCBI in the system browser. The app does not repeatedly poll NCBI. An Internet connection is required for submission and results. Website links also contact their destination in the browser.

AI/provider responses cannot directly execute commands or read arbitrary files. Connected AI can invoke a bounded set of validated local design tools on a copy after you click Send. Successful designs open as new unsaved documents; original documents are preserved. External pasted proposals require explicit review and application. Do not send confidential context to an external service without deciding that its terms fit your work.

The release source folder and test installers contain the supplied pET-21b(+) example, public reference records, synthetic workflow/test examples and test-only cryptographic fixtures. They contain no private working documents or actual account credentials. Developer UI checks can download public checksum-pinned test samples, excluded from the app and release source folder.
