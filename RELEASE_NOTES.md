# PlasmidCraft 0.32

Prepared by **Huiwang Ai at the University of Virginia with ChatGPT Codex**. Contact: [huiwang.ai@virginia.edu](mailto:huiwang.ai@virginia.edu).

Test release of the PlasmidCraft desktop sequence workspace for Mac Intel, Mac Apple Silicon and Windows x64.

- Help now includes Getting Started, User Guide and Search, and direct shortcuts for mutagenic primers, editing/alignment, PCR/assembly, Gibson/HiFi and Golden Gate, codon optimization, protein analysis/BLAST, feature libraries/file formats and AI. Thirteen guides and their screenshots are bundled for offline reading, with full-text topic search, section navigation and cross-guide links in a separate movable window. Guide menu paths have been updated and editing drafts remain available while reading.

- Tight circular maps with full curved feature labels and SVG export. Activating tight mode hides restriction-enzyme markings automatically. The Common enzymes group contains the 23-enzyme preset without preselecting it. The default map displays up to 10 single cutters automatically. Editable Map checkboxes and explicit select/clear controls are independent of digest selection and support multiple cut sites.
- Circular/linear maps and a continuous scrolling DNA Sequence view with annotation, primer, complement, CDS codon and selectable six-frame protein tracks. Non-overlapping CDS share translation lanes; DNA and protein selections highlight together, with DNA-strand/protein copy and FASTA options. A clickable annotation overview stays below Map and Sequence, and annotation starts center in the sequence viewport. CDS translations display by default with one-letter/three-letter notation. Large sequences render nearby rows on demand.
- DNA editing, annotation tools, branching edit history, native documents and GenBank/FASTA/SVG/SnapGene format exchange.
- Auto annotation from Tools and feature controls, with a choice of one library or all libraries and a preview/apply workflow. Imported libraries support up to 2,000 entries and 2,000,000 pattern bases each. Same-name identifications at the same segment/strand merge without regard to case. Search across all feature libraries, merge equivalent identifications while retaining source names/aliases, and avoid duplicate annotation. Public feature libraries with 68 entries, including one Myc tag entry that retains all eight synonymous DNA pattern families; 407 restriction-enzyme entries, primer design and PCR simulation. Local SnapGene `.ftrs` feature-list imports are supported; see the [import guide](docs/FEATURE_CATALOG_AND_EXCHANGE.md#import-features-from-an-existing-snapgene-installation).
- Sanger trace/alignment tools, whole-plasmid alignment with strand/origin controls, and Gibson/Golden Gate design workflows.
- Primers from selected DNA, editable oligos, mismatch highlighting, insertion/deletion editing and mapped placements. PCR defaults to a configurable 15-base exact 3′ anchor and can retain upstream mismatches and indels; full-region matching is also available.
- Mutagenic primer design integrated into Primer Design for DNA/residue substitutions, insertions, deletions and degenerate libraries, with a choice of exact oligo coverage or extra diversity, reviewed oligo exports and mutant DNA copies. Choose Gibson/HiFi homology with overlapping ends (default), or non-overlapping inverse PCR with KLD; preview both the linear PCR product and the circular mutant.
- Protein analysis, protein-to-DNA conversion and single/dual-host codon optimization.
- Docked Internal AI Operations accepts direct requests, runs validated local design tools on copies and opens new unsaved documents. Conversations show newest messages first; CDS inspection and residue editing use locally verified numbering. External AI retains prompt preparation and reviewed JSON proposals. Account setup stays in the AI menu; model discovery and macOS Keychain remembering are available.
- Larger interface text, movable modeless editing windows, width-adaptive sequence rows, CDS numbering every five residues, and the supplied pET-21b(+) default plasmid.
- Whole-plasmid comparison supports imported or pasted queries, strand/origin search, difference navigation and reference-feature transfer. Generated query copies explicitly label substitutions, insertions, deletion junctions and uncertain DNA.
- Gibson/HiFi mutagenic primer pairs balance overlap allocation and binding melting temperatures where constraints permit; local ambiguity is handled without rejecting otherwise usable templates. Biological descriptions and provenance/edit notes are displayed separately.

Mac test apps are ad-hoc signed without notarization; Windows is unsigned. See docs/RELEASE.md for installation/signing and docs/VALIDATION.md for verification status and remaining native-device acceptance. Local biology tools work offline; external AI and BLAST require explicit data submission. There is no autosave/crash recovery. Save `.pcraft` documents and export feature-library backups.
